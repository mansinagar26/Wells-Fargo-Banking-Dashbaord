# Wells Fargo Banking Performance Dashboard

![Dashboard Preview](wells_fargo_dashboard_preview.png)

## Project Overview

This project demonstrates a Power BI-style financial dashboard analyzing key banking performance indicators such as revenue, profitability, loan growth, and deposit trends.

## Tools Used

- Power BI-style dashboarding
- Excel Data Model
- Financial KPI Analytics

## Dataset

Monthly banking performance metrics including:

- Net Interest Income
- Non-Interest Revenue
- Operating Expenses
- Loan Balance
- Deposit Balance

## Key Measures

- Total Revenue
- Operating Profit
- Profit Margin
- Loan Growth
- Deposit Growth

## Data Governance

### Refresh Process

1. Update dataset
2. Refresh Power BI model
3. Validate KPI measures
4. Republish dashboard

### Refresh Frequency

Monthly
